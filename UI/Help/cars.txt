Транспортные средства:<br><br>
<tab>В некоторых случаях существует возможность использования транспортных средств:<br><br>
<tab>-<sp> Для того чтобы сесть в транспорт, необходимо подойти к нему с водительской стороны и выбрать соответствующий пункт из <l="game:UI\Help\menu.txt">'Меню действий'</l>.<br> 
<tab>-<sp> Управление транспортом производится с помощью клавиш движения ( по-умолчания W/A/S/D ).<br>
<tab>-<sp> Вылезти из машины можно с помощью клавиши 'Меню действий' ( по-умолчанию 'E' ) либо с помощью правой кнопки мыши, после полной остановки транспорта.<br>
<tab>-<sp> В грузовых машинах с тентом можно прятать тело, поднеся его к задней части транспорта и воспользовавшись соответствующим пунктом из <l="game:UI\Help\menu.txt">'Меню действий'</l>.<br>
<tab>-<sp> В открытом транспорте (некоторые модели легковых машин и мотоцикл) можно перевозить тела на сидениях (или люльке для мотоцикла), но при этом тела будут заметны для противника.<br>
