Update 1.16+ from 12.11.2026 [tested on russian GOG versions] (Wunder)
----------------------------------------------------------------------

The problematic mod files from v1.16 (briefing, Equipment, strings) have been translated into Russian.
Cyrillic fonts have been restored.
The issues with converting scripts containing Cyrillic characters to shadvs stemmed from an incorrect script encoding (UTF-8). Therefore, ALL scripts were successfully converted again, first to ANSI (CP1251) and then to shadvs.
The story mode of both game campaigns has been restored - missions are unlocked sequentially as the game progresses. Now MoT starts seamlessly after the end of the original game.
ALL cutscenes from both game companies have been restored with the correct field of view for widescreen monitors.
The cutscenes from the original game have been fully ported to the MoT game engine.
The 3D model of Strogov's head (from MoT) has been transferred to the cutscenes of the original game (this was the most challenging to implement, as we had to create a new hybrid 3D model of the head compatible with the old 3D model of Strogov's body and redraw the textures).
The mission loading screens feature a visually appealing Russian-language title positioned right in the center of the screen.
Video files: intro-1.vid - Haggard, intro-2.vid - DtS.
You can assign the middle and both side buttons of the mouse (MB3, MB4, MB5).
The "Holster Weapon" function has become "Holster / Draw Last Weapon" (convenient to assign to the middle mouse button, like in Hitman).
Two new (customizable) keys have been added for quick actions – "Change Clothes" ('T') and "Pick Up Body" ('B').
The mouse wheel zooms the map in the Briefing and the mini-map during free movement (instead of changing the stance).
The +/- keys adjust the camera distance from the character in increments directly in the game. The range of distance values is moved closer to the character (as in Hitman).
The restriction on the use of >2GB of memory by the game engine has been removed (eliminates crashes due to memory leaks when reloading levels).
Full support for high-resolution widescreen monitors [21:9] in the HUD (the basic 800x600 interface frame has been replaced with coefficients and adaptive mathematics).
Correct font scaling at any screen resolution.
High-quality voice acting for Russian-speaking male and female NPCs (replacing the Tarapunka and Shtepsel characters from forlik).
The environment alarm for taking out the Garrotte and Chloroform has been disabled (as in Hitman).
A small round map in the lower-right corner of the screen (the size is the same as the vehicle speedometer).
The default control key profile is the same as in Hitman.
After throwing a Knife, the next Knife or other bladed weapon is immediately drawn.
The 'ACTIONS' label at the top of the Actions Menu has been removed (HUD has been redrawn).
'Walk' mode is set as the default instead of 'Run'.
The "-profile name" key in the shortcut properties eliminates the need to select a player profile.
Screen anti-aliasing 6x (an experimental feature of old ATi cards) has been replaced with universal 8x.
Fixed the selection of incorrect color depth when loading a level and resetting the resolution to 800*600 when changing graphics settings on non-standard resolutions (16:6).
The useless minimap has been replaced with a truly useful, functional Compass featuring target markers that take into account the elevation of the targets.
New fast unpacker and packer of game resources into VFS format with Zlib compression support (Death to Spies .vfs Packer & Extractor v2.0).

MoTmod 1.00 from 23.10.2009 (forlik)
------------------------------------

Version 1.00 contains 18 missions (incl. training) on the MoT engine. Some
models from DtS missions are replaced by MoT models. Cinematics are disabled
for all missions. Graphical posteffects are removed from MoT missions. Some
weapon's and equipment's names are corrected. Version 1.00 doesn't contain new
scripts, models, sounds, textures and it's closest to the original DtS and MoT
games.

Warning! Demo version (0.8b) resources are not compatible with version 1.00.

Installation steps:

1. Unpack the resources of both games (DtS and MoT) using vfsTool.exe (or vfsTool2.exe)
2. Copy unpacked DtS resources to MoT folder without file replacing
3. Unpack MoTmod core files and copy them to MoT folder with file replacing
4. Unpack MoTmod additions (english translations, etc.) and copy them to MoT
   folder with file replacing
5. Delete (moving to another folder is recomended) packed MoT resources
   (8 vfs-files)
6. Run installation script MoTmod+.cmd (it will patch the largest SWD files, the game executable, and delete tmp files)
7. Pack the resources folders separately back to .vfs using vfsTool2.exe
8. Run the game and create a new profile

Step#4 & #6 is optional.
